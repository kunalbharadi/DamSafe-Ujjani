# Retained terrain execution evidence

These manifests and logs record earlier local D-Flow executions. They are generated DamSafe evidence, not redistributed engine software or Copernicus rasters. The repository does not currently declare a redistribution licence; upstream engine and input licences remain independent. DEM rasters and native outputs are excluded from Git.

Classification: approximate Ujjani numerical demonstration, not calibrated or observed-event validated. These files do not establish current engine availability. See PROJECT_STATUS.md and DATA_MANIFEST.md in the parent documentation directory.
